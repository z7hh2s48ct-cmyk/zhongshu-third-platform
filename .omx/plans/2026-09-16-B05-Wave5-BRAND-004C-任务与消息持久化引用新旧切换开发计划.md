**设计决策：**

1. **静态门禁循 `.B` 值级判定口径**（`scripts/brand/verify-brand-004c-persistence.mjs`，新增）：git ls-files 全量提取后只对「提取出的标识/字面量」做旧名判定，不重复 G3 全仓文本扫描、不误伤已登记署名注释/pom 上游 URL。提取器五组：①infra_job 种子 handler_name（解析 INSERT 列序取 handler_name 值）+ Java `implements JobHandler` Bean 名集合（种子 ⊆ Bean 名合同）；②QRTZ 面：`INSERT INTO QRTZ_` 种子行数恒 0 + SQL 面包形 FQCN（`cn.iocoder.`/`yudao.(module|framework)`）0 命中 + `JobBuilder.newJob(...)` 所指类必须 `cn.zszj.` 起源；③Outbox/Inbox：`AuditEventTypes` 常量、outbox/inbox 相关 SQL 字面量、恢复合同锚点（claim_token/NOT_DEAD/NO_SINK/白名单错误码）齐全；④MSG：`extends AbstractRedisStreamMessage|ChannelMessage` 子类 0 命中时登记、stream/channel 字面量判定、yaml key-prefix、`spring.application.name=zszj-server`、`@JsonTypeInfo(Id.CLASS)` 接口清单及其实现 FQCN 必须全新包根 + JsonUtils 无 default typing；⑤whitelist 配置锚点。旧名模式循 .B（yudao/ruoyi/iocoder/youdao/芋道/unibest/yd-）+ 包形增强（`cn.iocoder.`/`cn.yudao`）。
2. **注入自检防扫描器空洞**（≥9 组）：合成样例（旧名 handler_name 种子行、QRTZ 种子 INSERT 携旧 FQCN、AuditEventTypes 旧名常量、旧名 stream key、旧名 key-prefix、旧包根 @class FQCN、旧名 event_type、旧名 whitelist 锚点、包形 SQL FQCN）喂同一套提取+判定路径，任一未命中即门禁失败。
3. **运行期证明**（`scripts/brand/run-brand-004c-runtime.mjs`，新增）：一次性 Docker PG17+Redis + 真实 zszj-server（mock-enable=false、flyway off、quartz auto-startup=true 命令行覆盖、白名单=3 个 Bean 名、Druid PSCache 夹具级规避循 .B）。断言链（约 25 项）：基线键空间无旧名 → `job/sync` 重登记后 `QRTZ_JOB_DETAILS.JOB_CLASS_NAME` 全为 `cn.zszj...JobHandlerInvoker` 且恰 3 行与 infra_job 一致 → **预置旧 FQCN 的 yudaoLegacyJob QRTZ 行被对账孤儿清理**（受控迁移直证）→ infra_job 表行不被对账改写 → update-status(NORMAL)→trigger→`infra_job_log` 恰 1 行成功、完成后仍 1 行（**不重复副作用**）→ 白名单+Bean 存在双重受控拒绝旧式 handler 名（**不放开越权**）→ 预置 DEAD×2+PENDING×1 事件经 `outbox-event/health` 可见（**无静默丢失**）→ retry 成功（状态 PENDING+清租约+台账 RETRY 恰 1 行+audit 恰 1 行）→ 同事件二次 retry 被状态守卫拒绝（**重复消费无重复副作用**）→ skip 落 SKIPPED 终态不再可领取 → payload/headers/event_type 字节不变（**不做文本替换**）→ server.log 全程 0×`ClassNotFoundException|NoClassDefFoundError|cn.iocoder|yudao`（**无旧类找不到**）→ 终态键空间无旧名。
4. **无存量口径**：静态门禁 PASS（残留 0）+ 运行期证明 PASS = 本仓种子/迁移/持久化引用「无存量」的检查证据；真实遗留库（含 `infra_file_config` 类名落库、QRTZ 旧 FQCN 行）的升级执行归验收批次，运行期脚本内的旧名夹具为**受控注入对照**（预置后断言受控清理/拒绝，不污染终态）。
5. 失败语义：静态门禁退出码 0/1/2（循 .B）；运行期脚本缺 Docker 退出码 3、断言失败非零、退出自动清理（含 java 子进程 taskkill 双路径）。
