## 现状勘查

- `infra_file` PG 基线**无 tenant_id**；FileDO 类级 `@TenantIgnore` + BaseDO → 文件全局无租户隔离。
- 下载端点 `/{configId}/get/**` `@PermitAll + @TenantIgnore` → 私有附件匿名旁路（卡片点名）。
- H2 测试 schema 已有 tenant_id（默认 0）但 FileDO 未映射。
- deleteFileList 对「不存在/越权 id」静默跳过（selectByIds 租户过滤后查不到即略过）——批量混入越权必须显式拒绝。
- ApiInventoryTest 基线机制：`-Dapi.inventory.update=true` 重生成，diff 须仅含新端点。

## 交付（.A 技术账号范围）

1. **迁移** `V20260914.001__infra_file_tenancy.sql`：PG `infra_file` 加 `tenant_id int8 NOT NULL DEFAULT 0`、`owner_user_id int8 NOT NULL DEFAULT 0`、`scope varchar(16) NOT NULL DEFAULT 'PRIVATE'` + 索引；H2 schema 同步加 owner_user_id/scope。
2. **FileDO**：改 TenantBaseDO（去类级 @TenantIgnore），加 ownerUserId/scope；新增 FileScopeEnum（PUBLIC/PRIVATE）。
3. **写路径**：createFile（后端上传/presigned create）记录 ownerUserId=登录用户、scope=PRIVATE（历史迁移默认 PRIVATE，公开需管理员显式调整——「不能默认全部公开」）。
4. **读/删授权统一**：
   - 下载端点去 @TenantIgnore（保留 @PermitAll），yaml tenant.ignore-urls 放行该路径（匿名 PUBLIC 可读）；service `validateFileReadable(file, loginUser)`：PUBLIC 放行；PRIVATE 需登录且 LoginUser.tenantId==file.tenantId，否则 403。
   - deleteFileList 显式校验「全部存在」，混入越权/不存在 id 整批拒绝。
5. **update-scope 管理端点**（@PreAuthorize infra:file:update）：PUBLIC/PRIVATE 显式切换；ApiInventoryTest 基线重生成并审查 diff 仅含新端点。
6. **TDD**：FileServiceAuthorizationTest（H2）：默认 PRIVATE+租户+owner 落库 / PUBLIC 匿名可读 / PRIVATE 匿名拒 / 他租户登录拒 / 同租户登录可读 / 批量混入越权整批拒绝且零删除 / update-scope 合法与非法。
