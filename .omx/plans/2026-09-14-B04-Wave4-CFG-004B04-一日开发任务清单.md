## 1. 主线：ZS-CFG-004 B04 复验部分（变更审计 + 恢复流程）

卡片口径（docs/05 §9）：
- 记录旧/新值摘要、版本和操作者；敏感旧值不写审计原文；
- 支持审查后恢复；恢复不会绕过权限或复活关闭模块；并发更新冲突明确。

交付拆解：
1. **变更审计接线 AuditPort**（消费 AUDIT-001 成果，B04 同库审计）——infra config 的 create/update/delete 落 audit_event：eventType 按 `<域>_<对象>_<动作>`（CONFIG 域），detail 只写**脱敏摘要**（SECRET/SENSITIVE 按 ConfigSensitiveClassifier 掩码，NORMAL 记值摘要），含 version、operator、trace。
2. **配置变更历史 infra_config_history**（迁移 `V20260914.011`，开工前已探测他区未领号）——记录 key、old/new 值（SECRET/SENSITIVE 存掩码标记不可恢复、NORMAL 存可恢复原文）、版本、操作者、原因；H2 schema 同步。
3. **恢复流程**——恢复端点走与更新同一权限（@PreAuthorize）+ ConfigValueValidator 值校验 + 乐观锁版本 + 审计；SECRET/SENSITIVE 历史不可恢复须显式报错（管理员手工重录）；命中模块开关类 key 的恢复不得复活已关闭模块（CFG-003 联动守卫）。
4. **测试（TDD）**——审计脱敏（敏感旧值不出现在 audit_event）、恢复正向/版本冲突/敏感拒绝/模块守卫、历史落库；config 套件全绿。
5. **收口**——codex 评审弧至 0×P0/P1 → `--no-ff` 合并 main → 合并后复跑门禁（G3 假阴性教训）→ docs/05 串行同步 + reviews/README 索引 + 一致性校验。
