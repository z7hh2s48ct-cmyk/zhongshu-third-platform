## 4. 可重复执行入口

在项目根目录运行复制快照核验：

```bash
node --check scripts/verify-source-copy.mjs
node --check scripts/verify-source-copy.test.mjs
node --test scripts/verify-source-copy.test.mjs
node scripts/verify-source-copy.mjs
```

该核验读取固定的导入清单，不依赖原仓库继续存在。它是迁入时点的证据，不是未来修改后仍须保持源文件哈希不变的业务回归测试；后续二开必须保留 Git 差异，不得通过覆盖清单掩盖未审查改动。清单自身以项目 Git 历史保护，不提供对任意被一起篡改的清单和源码的真实性证明。

在 `services/zhongshu-core`、已正确设置 JDK 17 的环境中：

```bash
mvn -o -B -ntp test
mvn -o -B -ntp -DskipTests package
```

`-o` 使用本机已有依赖缓存；新电脑需要在审核依赖后联网获取锁定依赖。包构建中的 `-DskipTests` 不是测试结果，必须与上面独立执行的测试报告区分。

Web 的复现命令为 `pnpm run ts:check` 和 `pnpm run build:prod`；UniApp 为固定锁文件安装、`pnpm run type-check`、`pnpm run build:mp-weixin`、`pnpm run build:h5`。须在各自工程目录中运行。此处列的是入口，不将未执行的命令标记为通过。
