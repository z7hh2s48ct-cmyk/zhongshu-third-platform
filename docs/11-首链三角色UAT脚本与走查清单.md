# 首链三角色 UAT 脚本与走查清单（B10 交付物前置）

> 版本：V1.0（2026-10-02）
> 定位：B10 批次「平台/负责人/员工真实角色 UAT 脚本」的交付物前置（[docs/03 §B10](03-底座二次开发顺序与验收标准.md)：**真实角色 UAT 报告单列，不能由自动化测试代替**）。真机/真实账号到位后按本清单逐条执行并留证；执行结论写入 `docs/reviews/acceptance-<日期>-B10-UAT.md`（模板见 §8）。
> 服务端能力基线：首链三卡 FC-001/002/003 均已验收（docs/05 V2.12+）；接口契约以 ApiInventory（firstchain 19 端点全 PERMISSION）与各卡验收报告为准。

## 1. 执行环境与账号准备

| 项 | 要求 |
|---|---|
| 环境 | 长驻联验环境（`deploy/README-local.md`）或 G15 自举夹具 `--serve` 模式；Web（admin-web dev/build）+ 小程序（微信开发者工具/真机）+ H5 各一 |
| 数据复位 | 每轮 UAT 前以全新库跑全量迁移（含 V20261001.001 菜单 / V20261001.002 通知模板 / V20261002.001 选择器授权） |
| 账号矩阵 | 平台运营 A1（PLATFORM 任职，具备 `firstchain:application:*` + `firstchain:lead:distribute`）；负责人 L1（开业后由开通链创建，持 `firstchain:lead:assign/claim/reassign/followup/convert/invalidate/query` + `firstchain:employee:*`）；员工 E1/E2（由 L1 创建，持员工菜单面）；越权探针账号 X1（他租户 PLATFORM / 无任职账号） |
| 初始密码交付 | A1 审批通过后的开通结果弹窗与 L1 员工创建结果弹窗均**一次性展示**初始密码——执行人当场复制留存于证据表（不落任何系统日志） |

## 2. UAT-A：平台运营（Web）

| # | 步骤 | 预期 |
|---|---|---|
| A-1 | A1 登录 → 首链业务→加盟商申请 → 创建申请（填写申请方/联系人/资质附件编号） | 成功，列表出现 DRAFT 行，申请编号 `FC+日期+随机` |
| A-2 | 提交申请（可指定审批人；缺省=提交人） | 状态 SUBMITTED，版本+1；A1 收到「申请待审批」站内信 + 待办 |
| A-3 | 审批通过（填意见） | 开通结果弹窗展示组织编号 + **一次性初始密码**（复制留存）；站内信「审批通过并开通」致提交人/新负责人 |
| A-4 | 重复点击通过（同一申请再审批） | 返回既有组织，初始密码栏为空（不重发） |
| A-5 | 第二条申请走拒绝分支（意见必填） | 状态 REJECTED，不产生组织/负责人；站内信致提交人携意见 |
| A-6 | 线索管理 → 下发线索（填客户姓名/手机号/归属组织=L1 组织编号） | 成功；L1 收到「新线索已下发」通知 |
| A-7 | 视图核对 | A1 可见全租户线索（授权范围）；不做分配/领取按钮（权限串未授予时隐藏） |

## 3. UAT-B：加盟商负责人（Web + 小程序）

| # | 步骤 | 预期 |
|---|---|---|
| B-1 | L1 以初始密码首次登录 Web（改密后置为登记边界，登录不强制） | 登录成功，导航仅呈现首链业务授权菜单 |
| B-2 | 员工账号页创建 E1/E2（用户名 4~30 字母数字） | 弹窗展示一次性初始密码；员工只进本组织 |
| B-3 | 非法用户名（含下划线/过短）创建 | 前端+后端双重拒绝，不落库 |
| B-4 | 小程序 L1 登录 → 首链业务→线索工作台 | 仅见本组织线索（负责人视角） |
| B-5 | 线索详情 → 分配（员工选择器选 E1） | 成功；E1 收到「线索已分配」通知 |
| B-6 | 改派 E1→E2（选择器） | 状态保持 ASSIGNED、版本+1；E2 收到分配通知 |
| B-7 | 跟进中的线索执行无效关闭（选「其他」不填说明） | 受控拒绝；补说明后成功，状态 INVALID |
| B-8 | Web 员工账号页 → 组织成员列表 | 仅本组织在职成员（停职/禁用者不出现） |

## 4. UAT-C：员工（Web + 小程序）

| # | 步骤 | 预期 |
|---|---|---|
| C-1 | E1 以初始密码登录（Web/小程序各一次） | 登录成功，视图仅本人线索（员工视角） |
| C-2 | E1 领取分配给自己的线索 | ASSIGNED→FOLLOWING；L1 收到「线索已被领取」通知 |
| C-3 | E2 尝试领取同一线索（已在 FOLLOWING） | 受控冲突提示（状态/版本），页面数据刷新 |
| C-4 | E1 追加跟进（内容必填） | 成功；F2 字段（手机号/微信/地址）在 E1 视图**脱敏为尾四位** |
| C-5 | E1 转商机（先满足 ≥1 条跟进） | CONVERTED 终态；L1 收到「线索已结束」通知；商机落库且与线索双向引用 |
| C-6 | 终态线索上再跟进/再领取 | 受控拒绝（终态锁定） |
| C-7 | E1 视图核对 | 仅本人被分配线索；不可见他人线索详情（越权显式提示） |

## 5. UAT-D：通知与待办六节点核对（两端）

| 节点 | 触发 | Web 收件箱 | 小程序收件箱→落点跳转 |
|---|---|---|---|
| 审批（提交提醒） | A-2 | A1 收到 + 审批待办出现 | A1 有移动端则收信；落点 APPLICATION 域未注册 → 明确「暂不支持跳转」提示（CLIENT_UNSUPPORTED，非静默） |
| 审批+开通（通过/拒绝） | A-3/A-5 | 提交人+负责人收信 → 落点跳转申请详情页 | 同左（移动端落点 CLIENT_UNSUPPORTED 提示） |
| 下发 | A-6 | L1 收信 → 落点跳转 `/firstchain/lead` | L1 小程序收信 → 落点跳转线索详情（`?id=` 直达） |
| 分配/领取/结束 | B-5/C-2/C-5 | 对应收件人收信 | 同左（LEAD 域落点直达详情） |
| 失败不静默 | 临时停用通知模板后触发任一节点 | 业务不中断；`system_notify_send_log` 可查到失败状态（管理员侧） | 同左 |

## 7. 范围边界（不进本清单）

- B10 批次反向条款中的「已有系统接入」类（不共享生产库、来源 ID 映射、重复回传）属接入专项，随具体系统接入立项执行；
- 多实例/容量/弱网恢复归 B11（OPS-002.C / CLIENT-005.C）；
- 自动化回归（H2 85+/G14/G15/G16/PG 22 套件）已在各验收轮取证，UAT 不重复断言服务端逻辑，只验**真实角色可达性与页面一致性**。
