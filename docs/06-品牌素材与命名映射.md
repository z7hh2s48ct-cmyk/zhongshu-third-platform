## 2. 命名约定冻结

- 产品代码主前缀：小写 `zszj`；Java 类名前缀 `Zszj`；环境变量前缀 `ZSZJ_`。
- 允许的登记缩写仅限本文件第 4.3 节列明项；除登记项外不得新增 `zs` / `Zs` / `ZS_` / `yd` 等短前缀，不得与 `zszj` 混用表达同一概念。
- 用户口述的 "youdao" 在当前源码中的实际拼写为 `yudao`，映射以源码实际拼写为准；`youdao` 一并纳入残留扫描。
