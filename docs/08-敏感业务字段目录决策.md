## 1. 决策背景与范围

F0～F3 字段分级在 [docs/01 §8.3 权限输出契约](01-底座代码复用与改造方案.md) 中仅出现名称、从未定义语义；具体字段清单此前无任何草案。FND-AUTH-006 要求「F0—F3 与 authorized_fields 在报价、成本、佣金等域接入前完成」；ZS-PERM-003 卡明确「不提前固化报价成本等未批准业务字段」，等本目录获批。

本决策一次性批准四件事：

1. F0～F3 四级语义定义（§2）；
2. 等级 × 动作 × 角色的默认映射（§3）；
3. 首批敏感字段目录（§4：A 类一期首链线索域、B 类报价/成本/佣金域）；
4. 两项口径决策（§5：B 类拍板粒度、F2 呈现方式）。

**边界**：本决策只定级、不定字段存在性——A 类字段是否进入首链仍待 D-07 阶段 2 逐项确认（PEND-001）；本决策不提升任何实现验收状态；临时跨组织授权的双人审批与到期回收仍按 D-09 结论后置。

## 2. 字段等级定义（F0～F3）

| 等级 | 名称 | 语义 | 典型字段 | 越权表现 |
|---|---|---|---|---|
| F0 | 公开级 | 授权范围内所有角色可见 | 对象名称、状态、编号、描述 | （不适用） |
| F1 | 内部级 | 授权范围内可见；跨组织访问、低角色默认隐藏 | 跟进记录、进度、负责人 | 隐藏 |
| F2 | 敏感级 | 限组织负责人及以上管理角色 | 报价金额、预算、折扣、客户联系方式 | 默认脱敏（§5.2），不整字段隐藏 |
| F3 | 机密级 | 仅平台角色或显式授权 | 成本价、毛利率、佣金比例/金额、结算分成 | 拒绝，不泄露字段与对象存在性 |

## 3. 等级 × 动作 × 角色默认映射

| 动作 | 默认规则 |
|---|---|
| 读取 | 员工 ≤F1；组织负责人 ≤F2；平台角色 ≤F3 |
| 跨组织 visit 读取 | 字段维默认上限 F1；F2/F3 须经授权记录字段维显式放行（按 ZS-SEC-001.B 已交付的判定序字段步执行） |
| 编辑 | F0/F1 可由业务角色按既有功能权限编辑；F2/F3 字段编辑需显式权限点（随域接入在 ObjectAuthorizationProvider 候选动作中定义） |
| 导出 | 一律按读取等级收敛（FILE-004.B 通道「声明字段 ⊆ authorizedFields 否则拒绝」），不允许为导出放宽等级 |
| 错误信息/文件/批量旁路 | 机制层已 fail-closed 不回显（ZS-PERM-003.A 合同），无额外规则 |

## 4. 首批敏感字段目录

### 4.1 A 类：一期首链（线索域）

字段存在性仍待 D-07 阶段 2 逐项确认（PEND-001）；确认后按本表自动挂级，新增字段走 §7 回填流程。

| 字段 | 等级 | 说明 |
|---|---|---|
| 客户姓名 | F1 | 线索域核心业务数据 |
| 客户手机号 | F2 | 负责人可见完整，员工默认脱敏（尾四位，§5.2） |
| 客户微信号 | F2 | 同上 |
| 客户详细地址 | F2 | 同上 |
| 线索来源 | F1 | 过程数据 |
| 跟进记录内容 | F1 | 过程数据 |

### 4.2 B 类：报价/成本/佣金域（域级默认 + 字段回填）

按 §5.1 口径，本节只批域级默认；具体字段行随各业务域设计回填（回填时逐字段标注等级并入变更记录）。

| 业务域 | 域级默认等级 | 预置字段（建议稿，随域设计确认） |
|---|---|---|
| 报价域 | F2 | 报价单价、报价总价、折扣率、预算金额 |
| 成本域 | F3 | 成本价、毛利率 |
| 佣金域 | F3 | 佣金比例、佣金金额、结算分成金额 |

## 5. 口径决策

1. **B 类拍板粒度**：只批域级默认（报价域默认 F2、成本域/佣金域默认 F3），具体字段表随各业务域设计时回填本目录 §4.2——不替未设计的业务预锁字段清单。备选方案（现在逐字段定死）已否决，理由：D-07 阶段 2 设计变更会导致重新拍板。
2. **F2 呈现方式**：默认**脱敏展示**（手机号/微信号保留尾四位，规则可配置），非整字段隐藏；该口径约束前端消费合同（ZS-CLIENT-001.B）。F3 一律拒绝，无脱敏形态。

## 6. 落地与消费

- **ZS-PERM-003.B**（B08）：以本文件为唯一权威输入做 F0～F3 配置接入；验收按 docs/05 §16.1 该子项行执行（隐藏字段不能经详情/批量/导出/文件/错误信息旁路；按批准字段等级裁剪或拒绝；真实环境联验随批次放行）。
- **ZS-CLIENT-001.B**：前端只消费 `allowedActions`/`authorized_fields` 输出，不自行推断等级。
- **ZS-FILE-004.B**（已交付）：导出生成通道的字段维拒绝路径自本目录生效起按 §3「导出」行执行。
- **业务域接入**（D-07 首链与后续领域模块）：`ObjectAuthorizationProvider` 注册时按 §4 挂级；纪律为「目录先改、代码后接」，禁止在业务代码中散落等级硬编码。
- **机制合同提醒**（ZS-PERM-003.A）：`authorizedFields` 为 null 表示该域未启用字段级输出（零变化），非 null（可空集）才表示启用——目录回填不等同于域已接入。

## 7. 目录变更流程（后续修改入口）

1. 修改本文件对应表行（新增字段行、新增域、调整等级）；
2. §8 变更记录表新增一行：日期、版本、变更内容、依据；
3. 涉及 §2 等级语义或 §3 默认映射的变更，须同步 [docs/02](02-一期底座需求规格与待决策台账.md) PEND-008 行与 README 文档索引版本；仅 §4 字段行增补只需升本文档版本号；
4. 代码侧配置/Provider 注册随变更同步（ZS-PERM-003.B 交付后的配置入口），保持「目录先改、代码后接」。
